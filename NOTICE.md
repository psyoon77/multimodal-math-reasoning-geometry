# Public Release Notice

## Release type

Multimodal Math Reasoning: Geometry is presented as a limited, summary-only
research archive. It contains no software and is not intended to function as a
reproduction package.

## Materials intentionally excluded

- source code and executable notebooks;
- datasets, samples, labels, and answer material;
- architecture and implementation details;
- exact prompts, procedures, configurations, per-example measurements, and
  evaluation artifacts;
- checkpoints, generated outputs, experiment logs, and private reports; and
- repository history or private development records.

These omissions preserve the boundary around continuing research. Public
visibility of this summary does not grant access to or permission to reproduce
undistributed materials.

## Claims and attribution

This archive makes no claim of independent reproducibility, production
readiness, or current leaderboard performance. The aggregate accuracy values in
`README.md` are transcribed from the historical report and are not independently
reproduced here. External research is credited in `REFERENCES.md` and remains
subject to its original authorship and licensing terms.

No open-source software license is attached because this release contains no
software.
